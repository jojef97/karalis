# Karalis: BIM & VDC consulting website

Marketing website for a BIM/VDC consulting firm (client project).

**Stack:** Next.js · React · TypeScript · Tailwind CSS · custom CSS · Vercel

## What it does

- Multi-page marketing site, deployed on Vercel from GitHub.
- 11 service category pages generated from a single data file through one dynamic route, with 404 handling for invalid URLs.
- Reusable components (service tiles, navbar with active-route highlighting) and a responsive mobile menu.
- Responsive layout: detail side panel on desktop, accordion on mobile.

## Run locally

    npm install
    npm run dev

Then open http://localhost:3000.
